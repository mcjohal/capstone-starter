# Part 2. Get your copy

Your instructor's starter is a **template**. You make your own copy of it on GitHub, then download that copy to your computer. Allow about 10 minutes.

## Make your copy on GitHub

1. Sign in to GitHub.
2. Open the starter link your instructor gave you.
3. Click the green **Use this template** button near the top right, then **Create a new repository**.
4. Fill in the form:
   * **Owner:** your username.
   * **Repository name:** something about your topic, like `recipe-box` or `game-library`. You can rename it later.
   * **Public.** Render's free tier and your Capstone page both need it to be public.
5. Click **Create repository**. You now have your own copy at `github.com/your-username/your-repo-name`.

## Download it into VS Code

1. Open VS Code. If a folder is already open, choose **File**, then **Close Folder**.
2. Click the **Source Control** icon on the left edge (it looks like a branch with three dots), or press Ctrl + Shift + G.
3. Click **Clone Repository**.
4. Choose **Clone from GitHub**. If VS Code asks to sign in to GitHub, click **Allow** and sign in in the browser window that opens, then come back to VS Code.
5. Pick your new repository from the list.
6. Choose where to keep it, such as your Documents folder, and click **Select as Repository Destination**.
7. When VS Code asks whether to open the cloned repository, click **Open**.
8. If VS Code asks whether you trust the authors of the files, click **Yes, I trust the authors**.

## A quick tour

The Explorer on the left (Ctrl + Shift + E) shows the files. These are the ones that matter:

| File or folder | What it is | Do you edit it? |
|---|---|---|
| `config.py` | One line choosing which project the app runs | Yes, once |
| `projects/library_example/` | The finished library example | No, just read it |
| `projects/my_project/` | **Your project.** All your work goes here | Yes |
| `app.py`, `database.py` | The web app itself | No |
| `templates/`, `static/` | The page layouts and styles | No |
| `check.py`, `try_sql.py` | Tools you run in the terminal | No |
| `scratch.sql` | A place to try out SQL | Any time |
| `docs/` | This guide | No |
